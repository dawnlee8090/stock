메일 #$ARGUMENTS 을 검토해줘.

1. `python -m mailhub show $ARGUMENTS --json --max-chars 12000` 으로 본문과 첨부 내용(`att_text`)을 읽는다.
2. 같은 품번/제목/E.O 번호로 `search --group` 해서 과거 경과(이전 T/O 문제, 금형 수정 이력)를 확인한다.
3. 말투 참고:
   - `data/my_style.md` 가 있으면 반드시 읽고 그 인사말·표현·서명을 따른다.
   - 없으면 회신 상대에게 내가 보냈던 메일을 찾아 말투를 맞춘다:
     `python -m mailhub search --mine --to <상대 이름 또는 도메인> --limit 5 --json` → 2~3통 `show` 로 확인.
     (그리고 마지막에 `/mail-style` 로 말투 가이드를 만들어 두면 다음부터 빠르다고 알려준다)
4. 아래 형식으로 작성한다 (자동차 사출부품 개발 실무 관점).

### 1) 요약
- 발신/일시, 요청 내용 3줄 이내, 회신 기한

### 2) 요청사항 · 검토 항목
| No | 요청 내용 | 검토 주체(설계/금형업체/검사구업체/품질/고객사) | 기한 | 비고 |
- E.O 라면: 변경 부위, 금형 수정 방식(육성/가공/입자 교체/신규), 검사구 영향(C/F 수정 필요 여부),
  수정 리드타임, 비용 발생 여부, 기존 재고/양산 적용 시점을 점검 항목으로 넣는다.
- T/O 문제라면: 현상 → 추정 원인(성형조건/금형/제품설계) → 대책안 → 검증 방법.

### 3) 금형업체 전달문 초안 (해당 시)
### 4) 검사구업체 전달문 초안 (해당 시)
- 업체 요청에는 **반드시 회신 기한**을 넣는다. 기한은 고객사 회신 기한에서 내부 검토 시간(1~2 영업일)을 뺀 날로 제안한다.
- 요청 항목을 번호로 나열하고, 회신받을 산출물(수정 검토서, 수정 일정, 비용, 수정 전후 단면/3D 캡처 등)을 명시한다.
- 제목은 나중에 회신을 자동으로 찾을 수 있게 구체적으로: `[차종] 부품명 내용 요청 (회신 기한 M/D)`.

### 5) 고객사 회신 초안
- 내 말투를 따른다. 확정되지 않은 일정·비용은 "업체 검토 후 O/O까지 회신"으로 둔다.

### 6) 설계 데이터 반영 판단
- 반영 가능 / 조건부 가능 / 불가 / 업체 검토 후 판단 중 하나와 근거

### 7) 다음 조치 (실행은 사용자 확인 후)
- 업체 전달문을 보낸 뒤 회신 추적 등록 명령을 업체별로 제안한다 (제목은 실제 보낸 제목과 같아야 회신이 자동 인식됨):
  `python -m mailhub req add --to <업체 담당자 주소> --vendor <업체명> --subject "<보낸 제목>" --due <기한> --type <금형수정검토|수정진행|검사구수정> --mail $ARGUMENTS`
  업체 주소는 과거 메일(`search --from <업체명>`)에서 찾는다.
- 상태 기록: `python -m mailhub mark $ARGUMENTS --status 업체검토중 --note "..."`

메일은 절대 직접 보내지 않는다.
