description: 메일 1건 검토 → 요청사항 정리, 업체 전달문·회신 초안 작성 (예: /mail-review 1234)
---
메일 #$ARGUMENTS 을 검토해줘.

1. `python -m mailhub show $ARGUMENTS --json --max-chars 12000` 으로 내용을 읽는다.
2. 같은 품번/제목/E.O 번호로 `search` 해서 과거 경과(이전 T/O 문제, 금형 수정 이력)를 확인한다.
3. 아래 형식으로 작성한다 (자동차 사출부품 개발 실무 관점).

### 1) 요약
- 발신/일시, 요청 내용 3줄 이내, 회신 기한

### 2) 요청사항 · 검토 항목
| No | 요청 내용 | 검토 주체(설계/금형업체/검사구업체/품질/고객사) | 기한 | 비고 |
- E.O 라면: 변경 부위, 금형 수정 방식(육성/가공/입자 교체/신규), 검사구 영향(C/F 수정 필요 여부),
  수정 리드타임, 비용 발생 여부, 기존 재고/양산 적용 시점을 점검 항목으로 넣는다.
- T/O 문제라면: 현상 → 추정 원인(성형조건/금형/제품설계) → 대책안 → 검증 방법.

### 3) 금형업체 전달문 초안 (해당 시)
### 4) 검사구업체 전달문 초안 (해당 시)
### 5) 고객사 회신 초안
- 정중한 비즈니스 메일체. 확정되지 않은 일정·비용은 "검토 후 O/O까지 회신"으로 둔다.

### 6) 설계 데이터 반영 판단
- 반영 가능 / 조건부 가능 / 불가 / 업체 검토 후 판단 중 하나와 근거

마지막에 상태 기록 명령을 제안한다 (실행은 사용자 확인 후):
`python -m mailhub mark $ARGUMENTS --status 업체검토중 --note "..."`
메일은 절대 직접 보내지 않는다.
