E.O 리스트를 최신 메일 기준으로 갱신해줘. $ARGUMENTS (차종 등 범위가 있으면 그 범위만)

## 1. 현황 파악
- `python -m mailhub eo check` (새 메일 자동 연결 포함)
- `python -m mailhub eo list --json` (진행 중), 필요하면 `--status all`

## 2. 미등록 E.O 메일 → 등록 제안 (누락 방지)
- `python -m mailhub eo inbox --json --days 60`
- 각 메일을 `show <id> --json --max-chars 12000` 으로 읽는다. 첨부 E.O LIST(엑셀)·도면 변경 내역은 `att_text` 에 있다.
- 품번은 전체 형식으로 적는다. LH/RH 한 쌍은 `86525/26-BNGA0` 처럼 한 행에 줄여 써도 된다 (자동 연결 시 각각 풀어서 찾음).
  품번을 모르면 품명만 쓰고 "품번 미확인"이라고 표시해서 사용자에게 확인을 요청한다.
- E.O 1건에 품번이 여러 개면 **품번별로 1행**씩 뽑는다:
  E.O 번호 / 차종 / 품번 / 품명 / 변경 내용(무엇을 어떻게, 치수 포함) / 발행처 / 적용 시점 / 금형 수정 필요성 추정
- 이미 리스트에 있는 항목(같은 품번+같은 변경)이면 새로 만들지 말고 `eo link <E번호> <메일번호>` 를 제안한다.
- E.O 와 무관한 메일(단순 일정 공유, 견적 등)은 "등록 불필요"로 따로 표시한다.
- 표로 보여준 뒤, 사용자가 확인한 항목만 등록한다:
  `python -m mailhub eo add --mail <메일번호> --eo-no .. --car .. --part-no .. --part-name .. --desc ".." --customer .. --apply ..`
  기한은 사용자가 정하게 하되, 고객사 회신 기한이 메일에 있으면 `--review-due` 로 제안한다 (업체 검토는 고객사 기한 1~2영업일 전).
  여러 건이면 CSV(`data/eo_import.csv`, 열 이름은 `eo export x.csv` 와 동일)로 만들어 `eo import` 하는 방법도 제안한다.

## 3. 진행 중 항목 → 상태 갱신 제안
- `✉새 관련메일` 이 있는 항목은 `eo show <E번호> --json` 으로 관련 메일과 업체 요청(req)을 보고, 새 메일 내용을 읽어 판단한다:
  - 금형업체 검토서 회신(수정 방식·비용·일정) → `검토중`→`수정요청` 또는 `수정불필요`, `--mold-action`, `--cost`, `--mold-due`
  - 수정 착수/완료 통보 → `수정중` / `수정완료`
  - T/O 결과(치수·외관 OK/NG) → `검증중` / `완료`, NG 면 메모에 문제점과 재수정 필요 여부
  - 검사구 영향 언급 → `--cf 필요|불필요`, `--cf-vendor`
- 변경 제안은 표로: E번호 | 현재 → 제안 상태 | 근거 메일(#번호, 날짜, 한 줄 요약) | 실행 명령
  `python -m mailhub eo set <E번호> --status .. --note "근거 요약" --mail <근거메일번호> [기타 필드]`
- 진행 중인데 **현재 단계의 기한이 비어 있는 항목**(검토중인데 review_due 없음, 수정요청·수정중인데 mold_due 없음,
  수정완료·검증중인데 verify_due 없음)은 따로 모아 "기한이 없으면 지연 알림이 안 됩니다"라고 알리고,
  메일에 나온 일정(예: "11/16 포장장", "D+40")으로 기한을 제안한다. D+N 은 업체 착수일 기준으로 날짜를 계산해 보여준다.
- 사용자가 승인한 것만 실행한다.

## 4. 지연·임박 정리
- 지연(⚠)·임박(⏰) 항목마다 다음 조치를 제안: 업체 독촉(`/mail-followup`, `req add --eo <번호>`), 일정 재협의, 고객사 사전 공유.
- 업체에 검토·수정을 요청하는 메일 초안이 필요하면 `/mail-review` 형식(기한 포함)으로 쓰고,
  보낸 뒤 `req add ... --eo <E번호>` 로 연결하면 업체 회신이 E.O 이력에 자동으로 남는다고 안내한다.

## 4-1. 참고 그림
- 새로 등록했거나 관련 메일이 늘어난 항목은 그림을 모은다: `python -m mailhub eo img <E번호> --collect` (PST 메일이면 `--outlook`)
- 결과 목록에서 서명 로고·무관한 사진처럼 보이는 그림(캡션·출처로 판단)은 `eo img <E번호> --remove 번호` 를 제안한다.
- 도면·PPT 그림이 없는 진행 중 항목은 "Win+Shift+S 로 캡처 후 `eo img <E번호> --paste --caption \"설명\"`" 을 안내한다.

## 5. 마무리
- 요약: 진행 중 N건 (상태별), 이번에 등록/갱신한 건, 지연 건
- 엑셀이 필요하면: `python -m mailhub eo export data/EO_LIST.xlsx --collect --open` (그림까지 모아서 저장 후 열기)

기록을 바꾸는 명령(`eo add`, `eo set`, `eo link`, `eo import`, `req add`)은 사용자 확인 후에만 실행한다. 메일은 보내지 않는다.
