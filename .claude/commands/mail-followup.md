description: 업체 요청 추적 현황 - 기한 지난 건·임박 건 정리, 재요청 메일 초안 (예: /mail-followup)
---
업체(금형·검사구 등)에 요청한 건들의 회신 현황을 정리해줘. $ARGUMENTS

1. `python -m mailhub req check` (업체 회신이 들어온 건은 자동으로 '회신받음' 처리됨) 후 `python -m mailhub req list --all --json`.
   - 이 단계에서 `--auto-send` 는 절대 붙이지 않는다.
2. 표로 정리: 상태 | R번호 | 업체 | 요청 제목 | 요청일 | 기한(D-day) | 재요청 횟수 | 비고
   - 순서: 기한 지남 → 오늘·내일 기한 → 진행 중 → 최근 회신받음(회신 메일 #번호, 회신 내용 한 줄 요약: `show <reply_mail_id>`)
3. 기한이 지난 건마다 재요청 메일 초안을 쓴다.
   - `data/my_style.md` 가 있으면 그 말투·서명을 따른다 (없으면 `/mail-style` 을 먼저 권한다).
   - 원래 요청 메일·관련 메일(`mail_id`)을 `show` 로 읽어서, 무엇을 언제까지 달라고 했는지 구체적으로 다시 적는다.
   - 재요청 횟수가 2회 이상이면 어조를 한 단계 단호하게, 일정 영향(고객사 일정, 이벤트)도 언급.
   - 사용자가 초안을 확인하면, 아웃룩 창으로 띄우는 명령을 안내한다: `python -m mailhub req remind <R번호>`
     (기본 템플릿 대신 이 초안을 쓰려면 사용자가 아웃룩 창에서 본문을 바꿔 붙여넣으면 된다)
4. 회신받은 건 중 검토서 내용이 충분하면 `req update <R번호> --status 완료` 를 제안한다 (실행은 사용자 확인 후).
메일은 직접 보내지 않는다. `req remind --send` 는 사용자가 명시적으로 요청할 때만 쓴다.
