> 시연 화면·동영상은 모두 가상 데이터입니다 (실제 회사 메일 미사용).

## 제목
AI 개발 업무 비서 도입 — 놓친 메일 3초 검색 · 회신 근거 정리 · 회신 초안 자동 작성

## 분류
제안 (업무 효율화 · AI S/W 적용)

## 무엇이
고객사 · 금형업체 · 검사구업체 · 현지 법인과 주고받는 개발 업무 메일
(E.O 변경 통보, T/O 결과 · 문제점, 금형 수정 검토, 검사구 수정, 금형 이관 서류, 일정 협의 등)

## 어떻게 되어
- 메일함 용량 제한으로 개인이 수동 삭제 · PST 백업을 하고 있어 과거 메일이 PC마다 흩어져 있음
- 아웃룩 키워드 검색은 **첨부파일(엑셀 · PPT · PDF) 안의 품번 · 내용을 찾지 못해** 메일을 하나씩 열어 확인함
- 회신 기한 · 업체 요청 기한 · E.O 금형 수정 일정 · T/O 대책 기한을 엑셀 · 수첩 · 기억에 의존해 관리함
- 회신 시 근거가 되는 과거 메일 · 첨부를 다시 찾고 요청사항을 정리하는 데 시간이 많이 걸림

## 문제점이 있는가
- 중요 메일 누락 · 회신 지연 → 고객사 회신 · 자료 제출 지연으로 고객 불만 발생
- 과거 E.O · T/O 이력을 찾는 데 1건당 5~10분 이상 소요, 첨부 속 내용은 사실상 검색 불가
- 담당자 변경 시 업무 이력이 단절되어 같은 불량 · 같은 E.O 문제가 반복 (재발 대책 이력 미활용)
- 금형 이관 시 사양서 · 성형조건표 · KD/원소재 리스트 누락이 선적 직전에 발견됨

## 무엇을
**개발 업무 비서(AI 메일 트래킹 · 회신 초안 시스템)** 를 개발 담당자 PC에 도입
— 이미 개발 · 실사용 중인 프로그램(파이썬 + 로컬 DB + Claude AI)을 개발팀 시범 적용 후 확산

## 어떻게 개선하면
1. **통합 보관 · 검색**: 서버 메일 + 아웃룩 PST 백업 + 저장된 메일(.msg/.eml)을 내 PC 검색 DB 하나로 모으고 중복 제거.
   품번 · 차종 · 업체 · 내용은 물론 **첨부 엑셀 · PPT · PDF 안의 글자까지** 3초 안에 검색
2. **자동 분류 · 누락 방지**: E.O · T/O · 금형수정 · 검사구 · 품질문제 · 금형이관 · 일정으로 자동 태깅,
   차종별 폴더 자동 생성, 내가 받는 사람인 요청 메일은 **[회신 필요]** 로 자동 분류
3. **[오늘] 한 화면**: 회신 필요 메일 · 업체 회신 기한 · E.O 지연 · T/O 대책 지연 · 금형 이관 확인 필요를
   급한 순서로 정렬, 기한 · 일정 항목을 누르면 관련 메일이 바로 열림
4. **AI 검토 · 회신 초안**: 메일 화면에서 `✦ 검토·회신 초안` 버튼 → 메일 본문과 첨부를 읽어
   ① 요약 · 회신 기한 ② 요청사항 · 검토 주체 · 기한 표 ③ 근거 메일 번호 ④ 고객사 · 업체 회신 초안을 자동 작성.
   **발송은 자동으로 하지 않고 담당자가 확인 후 직접 발송**
5. **E.O 리스트 자동 기입**: E.O 통보 메일에서 E.O 번호 · 품번 · 변경 내용 · 기한을 자동 추출 → 확인 후 등록,
   접수 → 검토 → 금형 수정 → 검증 → 완료 단계와 지연 · 임박 자동 표시, 관련 메일 자동 연결
6. **T/O 문제점 · 개선 이력 DB**: 불량 1건 단위로 원인 → 대책 → 효과 확인 이력 관리,
   **같은 부품 · 같은 불량 재발 자동 감지**, 과거 유효 대책 · 불량 유형별 원인 · 대책 가이드 제시
7. **금형 이관 종합장**: 금형별 사양서 · 성형조건표 · 부품 · KD · 원소재 리스트 · 선적 일정 체크 매트릭스,
   선적 전 미완료 서류 자동 알림 → 현지 법인 양산 이관 누락 방지
8. **업체 요청 추적**: 요청 건별 회신 기한 D-day, 회신 도착 시 자동 확인, 기한 경과 시 재요청 메일 창 준비
9. **보안**: 메일 DB는 담당자 PC에만 저장(외부 서버 업로드 없음, 화면은 127.0.0.1 전용),
   자동 발송 없음, 대장 기록 변경은 담당자 확인 후에만 반영

## 어떠한 효과가 있는가
- **누락 방지**: 회신 필요 메일 · 업체 기한 · E.O / T/O 지연을 매일 아침 한 화면에서 확인 → 회신 지연 · 고객 불만 감소
- **검색 시간 단축**: 첨부 속 품번까지 3초 검색 → 메일 · 첨부 검색 1건 8분 → 1분
- **회신 품질 · 속도 향상**: 요청사항 표 + 근거 메일 번호 + 회신 초안 자동 작성 → 검토 · 회신 1건 15분 → 5분
- **이력 자산화**: E.O · T/O · 금형 이관 이력이 DB로 남아 담당자 변경 · 신입 교육 시 인수인계 시간 단축,
  과거 유효 대책 재활용으로 T/O 재발 감소
- **현지 이관 원활화**: 이관 서류 누락을 선적 전에 발견 → 현지 양산 준비 지연 방지
