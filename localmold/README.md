# 현지 금형 육성 관리 (localmold)

현지 외주처(성형처)로 이관한 금형의 문제점을 **차종 → 외주처 → 금형(갑지) → 문제점(을지)** 로 관리하는 **별도 앱**입니다.
업무 비서(mailhub)와 따로 켜고 끄며, 데이터도 따로 둡니다. 화면 디자인과 진행 단계는 업무 비서와 같습니다.

- 양식: 드라이브의 **외주처별 문제점 관리 엑셀**(갑지 MASTER + 금형별 을지)과 같은 구조
- 진행 단계: T/O 문제점 대장과 같음 — **발생 → 원인분석 → 대책수립 → 대책적용 → 효과확인 → 종결**, 보류. 번호는 `L12` 처럼 L 로 시작
- 데이터: 내 PC 의 `data/localmold/` 에만 저장 (DB `localmold.db`, 사진 `photos/L번호/`, 엑셀 `export/차종/`). 저장소에는 올리지 않음
- 불량 유형 가이드(원인 · 대책)는 업무 비서 T/O 대장의 지식을 같이 씁니다 (`mailhub/to_knowledge.py`)

## 실행

```powershell
python -m localmold app        # http://127.0.0.1:8766 앱 창 (이 PC 에서만)
```

**바탕화면 앱 설치** (처음 한 번): `scripts\현지금형_앱_설치.bat` 더블클릭 (다른 폴더에 받아 두고 더블클릭해도 됨, 또는 `python -m localmold shortcut`).
업무 비서 폴더를 찾아(바탕화면의 업무 비서 바로가기 · 흔한 위치 · 못 찾으면 직접 고르기) 현지 금형 앱 파일이 없으면 최신 파일을 받고(git pull, 브랜치 변경은 물어봄)
→ 바탕화면과 시작 메뉴에 **'현지 금형 육성 관리'** 아이콘이 생깁니다. 아이콘을 더블클릭하면 앱 창이 열리고,
작업 표시줄에 최소화된 작은 검은 창 '현지 금형'을 닫으면 앱이 꺼집니다. 이미 켜져 있으면 창만 다시 엽니다.
업무 비서(8765)와 동시에 켜도 됩니다. 저장소 폴더를 옮겼으면 아이콘을 다시 만드세요 (`--desktop-only` 면 바탕화면에만).

업무 비서 안의 [현지 금형]에 넣어 둔 데이터가 있으면 **처음 한 번** 옮깁니다 (L번호 · 사진 · 이력 그대로, 업무 비서 DB 는 읽기만):

```powershell
python -m localmold from-mailhub
```

## 화면

| 메뉴 | 내용 |
|---|---|
| **전체 현황** | 진행 중 · 중요도 상 진행 · 수정 지연 · 검증 T/O 필요 · 종결률, 차종별 표(단계 막대), 작업 우선순위 상위 10 |
| **작업 우선순위** | 진행 중 문제점을 먼저 챙길 순서로 (차종 고르기). 이유가 같이 나옴: `수정 12일 지연` · `중요도 상` · `검증 T/O 필요` · `수정 후 T/O NG` · `재발 ← L42` · `수정 목표 D-2` |
| **차종** (왼쪽 목록) | 차종을 누르면 외주처가 펼쳐짐. 요약 · 외주처 탭 · **갑지 · 금형별** / **문제점 카드** |
| **폰 사진 접수** | 휴대폰 사진 접수 페이지 주소와 순서 |
| 위 검색창 | 모든 차종에서 품번 · 품명 · 문제점 · 대책 · 외주처 · L번호 |
| `엑셀 · CSV 올리기` | 외주처 엑셀 · 통합 리스트 · 금형 리스트 (자동 구분) |

- **갑지 · 금형별**: 금형마다 습합·취출·WELD·SINK·미성형·GAS·기타 건수, STATUS(그 금형 문제점 중 가장 앞 단계), 최근 발생일, T/O 차수
  → 금형을 누르면 **을지**(문제점 · 수정 전 사진 · 개선 대책 · 수정 후 사진 · 단계), `+ 문제점 추가`
- **문제점 카드**: 'DATA 수정 변경 검토서'와 같은 카드 (사진 썸네일 · 중요도 · 단계 · 지연/검증 필요/재발), 단계·중요도·유형·검색으로 거르기
- 문제점 상세: 문제점 · 유형 · 중요도 · 발생일 · 담당 · 개선 대책 · 수정 목표일 · 금형수정 대상 · 수정 후 T/O · T/O 결과 · 진행 메모 · 단계 · 메모(이력)
- **사진**: 수정 전 / 수정 후 칸에 `사진 촬영` · `파일 · 앨범` · 끌어놓기 · `Ctrl+V`
  - **끌어놓기 · Ctrl+V 는 바로 첨부** (문제점 창에서 지금 고른 칸, 칸 밖에 놓아도 같은 칸). 여러 장도 한 번에
  - 창을 열지 않아도 **문제점 카드 · 을지 행 · 우선순위 행에 사진을 끌어 놓으면** 그 문제점의 '수정 전' 칸에 들어감
  - `사진 촬영` · `파일 · 앨범`으로 한 장을 고르면 **표시 화면**부터: ◎ 동그라미+라벨 · ○ 동그라미 · ➜ 화살표+라벨 · □ 사각 · 펜,
    **수정부위(빨강) / 리워크부위(파랑)**. 바로 첨부한 사진은 `○ 표시`로 나중에 그림
  - 원본은 그대로 두고 표시만 겹쳐 저장, 엑셀에는 표시가 들어간 그림
- 수정 후 T/O 결과가 NG 면 종결할 수 없고, 결과(OK) 없이 종결하면 한 번 더 묻습니다. **금형 수정은 끝났는데 T/O 결과가 없는 건은 '검증 T/O 필요'**

## 명령

```powershell
# 가져오기 (파일 종류 자동 구분, 다시 올리면 바뀐 것만, 앱에서 고친 문제점은 덮어쓰지 않음)
python -m localmold import "D:\자료\BC4t CUV_CAR_ASHA-2_REV.1 (매크로).xlsx" --car "BC4t CUV"   # 외주처 엑셀 (갑지 + 을지 + 사진)
python -m localmold import "D:\자료\통합 금형 문제점 전체 관리 리스트_V4.csv" --car "BC4t CUV"   # 통합 문제점 리스트
python -m localmold import "D:\자료\NX5 금형 리스트.xlsx" --car "NX5 CUV"                        # 신규 차종 금형 리스트

python -m localmold cars                                   # 차종별 요약 (외주처별 포함)
python -m localmold top --car "BC4t CUV" --limit 20        # 작업 우선순위 (이유 포함)
python -m localmold molds --car "BC4t CUV" --vendor ASHA-2 # 갑지
python -m localmold list --car "BC4t CUV" --status wait    # 검증 T/O 필요 (open / all / 단계 이름)
python -m localmold show 12
python -m localmold set 12 --status 효과확인 --to-after O --note "11/20 T3 예정"
python -m localmold export --car "BC4t CUV" --vendor ASHA-2 --open   # 외주처 양식 (갑지 + 을지 + 사진)
python -m localmold export --car "BC4t CUV" --open                   # 통합 리스트 + 외주처별 전부
```

- 양식 상태 → 단계: 검토 중 → 원인분석, 개선 중 → 대책수립(진행 메모에 '수정 완료'가 있으면 대책적용), AQL 협의 → 효과확인,
  관망 → 보류, 개선 완 → 수정 후 T/O 가 OK 면 종결 · 아니면 효과확인(검증 필요), T/O NG → 대책수립. 원래 상태는 `양식 상태`로 남습니다.
- 외주처 이름은 파일 이름(`_CAR_외주처_REV`)이나 갑지 제목(`MOLD ISSUE LIST — 외주처`)에서 읽습니다.
  제목 오타(ASAH-5)나 직접 적은 이름의 띄어쓰기 · 줄임(SAFEDEMO, TEKNIKA)은 이미 있는 외주처(ASHA-5, SAFE DEMO, TEKNIKAPLAST)로 맞춥니다.
- 작업 우선순위 점수: 수정 지연(오래될수록, 최대 60일) > 중요도 상 > 검증 T/O 필요 · 수정 후 T/O NG > 재발 > 수정 목표 3일 이내 > 오래된 건.

## Claude Code

- `/local-sync`: 구글 드라이브 폴더의 외주처 엑셀 · 통합 리스트를 받아 가져오기 명령을 제안 (승인한 것만 실행)
- **휴대폰 사진 접수**: claude.ai 의 비공개 페이지 '현지 금형 사진 접수'에서 폰으로 차종 · 외주처 · 품번 → 진행 중 문제점(또는 새 문제점) →
  촬영 → 수정부위 표시 → 올리기. `/local-sync` 4-1 이 반영 대기 사진을 받아 `phone-import` 로 문제점 사진 칸에 넣고, 페이지에 'PC 반영 · L번호'를 표시합니다.
  폰에서 고르는 목록은 `snapshot` 으로 PC 와 맞춥니다. 페이지 원본: `localmold/web/phone_intake.html` (회사 데이터 없음, 목록은 페이지 저장소에)
